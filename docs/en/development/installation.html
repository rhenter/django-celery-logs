Development Installation¶

Requirements¶

  • Python 3.10 or later

  • uv

Development install¶

After forking or checking out:

cd django-celery-logs/
make deps
uv run --extra dev pre-commit install

The project stores runtime metadata in setup.py for PyPI and uses pyproject.toml for the build backend and development extras.

Running tests¶

make test

Run Django’s system checks against the bundled test project:

make check

Building the package¶

make build

Checking package metadata¶

uv run --extra dev twine check dist/*
