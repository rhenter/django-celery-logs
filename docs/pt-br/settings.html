Configurações¶

Result backend do Celery¶

Django Celery Logs foi pensado para substituir o armazenamento do result backend do Celery para inspeção de tasks. Configure o Celery para ignorar o backend de resultado padrão e serializar os dados da task como JSON:

CELERY_TASK_IGNORE_RESULT = True
CELERY_RESULT_SERIALIZER = "json"

Não habilite outros apps de resultado do Celery em INSTALLED_APPS para o mesmo objetivo. Por exemplo, remova django_celery_results se ele estiver instalado. Somente django_celery_logs deve ser adicionado, como mostrado na seção do app Django abaixo.

Se estas configurações existirem, remova-as, a menos que outra parte do projeto realmente dependa delas:

CELERY_RESULT_BACKEND = "..."
CELERY_CACHE_BACKEND = "..."

App Django¶

Adicione o app ao INSTALLED_APPS:

INSTALLED_APPS = [
    ...
    "django_celery_logs",
    ...
]

Django 4.2+ carrega automaticamente django_celery_logs.apps.CeleryLogsConfig para este app. O app config importa django_celery_logs.signals em ready(), registrando os signal handlers do Celery.

Execute as migrations:

python manage.py migrate

Retenção dos logs¶

Opcionalmente, configure por quantos dias os logs serão mantidos pela task de limpeza:

CELERY_TASK_LOGS_EXPIRES = 7

Se esta configuração não for definida, o app usa 2 dias por padrão.
