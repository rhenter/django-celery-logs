Release¶

Para publicar uma nova versão:

  • Atualize CHANGES.rst.

  • Revise os metadados e dependências em setup.py.

  • Revise a documentação.

  • Execute os testes com make test.

  • Execute os checks do Django com make check.

  • Gere o build com make build.

  • Verifique os metadados da distribuição com uv run --extra dev twine check dist/*.

  • Faça commit e push das mudanças.

  • Publique com make release.
