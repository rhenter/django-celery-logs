Instalação de desenvolvimento¶

Requisitos¶

  • Python 3.10 ou superior

  • uv

Instalação de desenvolvimento¶

Depois de fazer fork ou checkout:

cd django-celery-logs/
make deps
uv run --extra dev pre-commit install

O projeto mantém metadados de runtime em setup.py para o PyPI e usa pyproject.toml para o build backend e extras de desenvolvimento.

Executando testes¶

make test

Execute os system checks do Django contra o projeto de teste incluído:

make check

Gerando o pacote¶

make build

Verificando metadados do pacote¶

uv run --extra dev twine check dist/*
