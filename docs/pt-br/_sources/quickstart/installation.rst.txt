Installation
============

Requirements
------------

* Python 3.10 or later
* Django 4.2 or later
* Celery 5.3 or later

Install from PyPI
-----------------

Most users can install the package with pip:

.. code-block:: bash

   pip install django-celery-logs

If you use ``uv``:

.. code-block:: bash

   uv pip install django-celery-logs

Install from source
-------------------

.. code-block:: bash

   git clone git@github.com:rhenter/django-celery-logs.git
   cd django-celery-logs
   pip install .

If you use ``uv``:

.. code-block:: bash

   uv pip install .
